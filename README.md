## Airbnb Listings Dashboard – Chicago vs New Orleans

## Introduction  
This project presents a comparative visual analysis of Airbnb listings in Chicago and New Orleans using Tableau Desktop, Tableau Public, and Power BI. By leveraging the visual analytics capabilities of these tools, the dashboard uncovers key patterns in listing types, pricing, host behavior, and guest engagement. The goal is to explore market dynamics and provide insights into how Airbnb functions in different urban environments.

## Problem Statement  
The short-term rental market varies greatly from city to city, influenced by local tourism, regulations, and neighborhood characteristics. To better understand these differences, this project examines Airbnb listings in Chicago and New Orleans. By analyzing core metrics such as pricing, room types, neighborhood popularity, and host activity, the project aims to highlight how each city positions itself within the Airbnb ecosystem and what factors contribute to market competitiveness and user engagement.

## Insights  
1. **Total Listings**  
   - Chicago has 6,593 listings, while New Orleans has 245 listings, indicating a significantly larger market in Chicago.

2. **Room Type Distribution**  
   - Entire Home/Apt is the most common listing type in both cities, accounting for 84.13% of listings in Chicago.

3. **Average Price**  
   - Chicago: $151.6  
   - New Orleans: $346.6  
   - The higher average price in New Orleans may reflect limited supply or a focus on premium experiences.

4. **Top Neighborhoods by Listings and Price**  
   - **Chicago**  
     - Near North Side: 916 listings, $346.6 average price  
     - Loop: 515 listings, $295.5  
     - West Town: 772 listings, $278.0  
   - **New Orleans**  
     - Central City: 629 listings, $197.1  

5. **Host Analysis**  
   - Certain host brands like Blueground are prominent in Chicago, with up to 175.6 listings.  
   - A correlation analysis shows how different host types influence review volumes and pricing patterns.

6. **Review Dynamics**  
   - Listings in Chicago tend to receive more reviews, suggesting higher guest activity and engagement compared to New Orleans.

7. **Visualization Techniques**  
   - Heatmaps illustrate pricing trends across neighborhoods.  
   - Bar charts display listing distributions.  
   - Correlation plots reveal relationships between price, review counts, and host types.

## Conclusion  
Chicago represents a broader and more budget-friendly Airbnb market, while New Orleans shows a more premium-focused approach with fewer listings and higher average prices. These differences offer valuable insights for hosts, investors, and travelers. Understanding these patterns can help in setting competitive prices, targeting high-demand neighborhoods, and tailoring listings to attract more guests.
